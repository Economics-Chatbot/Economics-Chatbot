# Functional Requirements Summary

## PoC 목표

사용자가 정확한 경제용어를 입력하지 않아도 관련 용어를 검색하고, 공식 정의를 바탕으로 쉬운 설명과 출처를 제공할 수 있는지 검증한다.

## P0 기능

- `FUNC-001`: 자연어 경제용어 질문
- `FUNC-002`: 관련 경제용어 검색
- `FUNC-003`: 쉬운 답변 생성
- `FUNC-004`: 공식 출처 표시 및 관련 키워드 표시
- `FUNC-005`: 검색 실패 안내

## 답변 구조

정상 답변은 다음 항목을 포함한다.

- 용어명
- 한 줄 정의
- 쉬운 설명
- 생활 속 예시
- 관련 키워드
- 출처

## 검색 실패 원칙

다음 상황에서는 LLM이 임의로 답변하지 않는다.

- 검색 결과가 없음
- 검색 점수가 기준보다 낮음
- 경제와 관련 없는 질문
- 공식 정의 또는 출처가 없음

## 화면 범위

단일 챗봇 화면만 구현한다.

필수 요소:

- 서비스명
- 한 줄 설명
- 질문 입력창
- 전송 버튼
- 사용자 질문 영역
- AI 답변 영역
- 로딩 표시
- 출처 표시
- 오류 메시지
